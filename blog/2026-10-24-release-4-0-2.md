We are excited to announce the release of **ABCD v4.0.2**. This maintenance release is highly focused on correcting and stabilizing the **Update Manager** itself, addressing critical bottlenecks that affected users upgrading from versions 4.0.0 and 4.0.1.

### 🛠️ What’s New in v4.0.2?

The transition to the ABCD 4 architecture introduced a new batched AJAX processing system to the Update Manager, preventing screen freezes and server timeouts. However, versions 4.0.0 and 4.0.1 encountered three unintended side effects:

1. **Extraction Infinite Loop:** The extraction phase would hang in an infinite loop because the system failed to recognize the "success" string returned by the server, a problem exacerbated if your interface was not set to English.
2. **Aborted config.php Update:** A premature shutdown hook falsely assumed the update process was incomplete (logging `config.php v4 NOT applied`), which aborted the new configuration merge.
3. **Fatal Error ("Main config not found"):** During the replacement of the main core directory (`central/`), the configuration file was temporarily wiped from the disk and not restored in time for the next batch request, triggering a fatal error.

We have successfully resolved these issues in **v4.0.2**. Furthermore, we have introduced a **"Pre-Download Self-Update"** mechanism. Moving forward, the Update Manager will update itself before downloading and applying any core ABCD files, ensuring you always execute the safest and most recent update logic.

### 📖 How to Update to ABCD 4.0.2

The path to update depends entirely on your current ABCD version.

**➡️ For Users Upgrading from v3.9.x:**
You can proceed normally! The legacy Update Manager in the 3.9 series runs the installation in a single monolithic request, so you are not affected by the bugs mentioned above. You will transition smoothly into the v4 architecture.

**➡️ For Users Currently on v4.0.0 or v4.0.1:**
Because your current Update Manager contains the extraction loop bug, **you cannot update directly using the standard "Update" button**.

However, thanks to ABCD 4's new modular architecture, you can apply this hotfix directly from your browser—no SSH or FTP access required!

To ensure a smooth process, we have created a quick step-by-step video tutorial. **Please watch the tutorial before proceeding:**
🔗 **[Watch the Update Tutorial Here](https://www.youtube.com/watch?v=DO-Tw23q0jM)**

**Step-by-Step Instructions:**

1. Go to **Configuration ABCD** -> **Plugins**.
2. Locate the **"ABCD Update Manager Hotfix"** in the plugin list. *(Note: The update notification is already visible at the bottom of the page, but **do not click it yet**).*
3. Click **Install**, wait a few seconds, and then click **Activate**.
4. Click on **Settings** within the active plugin list (or click the link inside the green notification bar at the top of the screen).
5. Your Update Manager is now patched! You can safely navigate to the Update Manager and proceed with the ABCD 4.0.2 update as usual.

*(Please be patient during the final installation stage of the Update Manager, as the system takes a few moments to clear temporary files. Wait until the "Reload Page" button appears).*

Once you have successfully updated to v4.0.2, the self-update system will be active, and the Hotfix plugin can be safely deactivated and removed.

Thank you for your continuous support. Be sure to subscribe to the ABCD YouTube channel for more tutorials and updates!
